# ZIAD HOST v6 - نظام استضافة سحابي احترافي

  ## 🚀 تشغيل المشروع

  ### المتطلبات
  - Python 3.8+

  ### التثبيت
  ```
  pip install -r requirements.txt
  python app.py
  ```

  ### بيانات الدخول الافتراضية
  - البريد: admin@ziadhost.com
  - الكلمة: admin123

  ### متغيرات البيئة
  - PORT - رقم المنفذ (افتراضي: 5000)
  - SECRET_KEY - مفتاح سري
  - ADMIN_EMAIL / ADMIN_PASSWORD
  - BOT_TOKEN / ADMIN_TELEGRAM_ID - للإشعارات
